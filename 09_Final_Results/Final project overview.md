# 1. Final Project Overview

This project developed a simulation-based and machine-learning-assisted framework for the analysis and optimization of an ethanol–water extractive distillation process using ethylene glycol as the entrainer.

The process was first implemented in DWSIM based on the published extractive-distillation case of Purgatto et al. (2016). A dataset of 73 converged process simulations was generated by varying key operating conditions of the two-column separation system.

Engineering analysis was then performed to identify the major operating variables, process trade-offs, and high-performance operating regions. A Process Performance Index (PPI) was developed by combining ethanol purity, average recovery of ethanol and ethylene glycol, and normalized energy performance.

Machine-learning models were subsequently trained to predict PPI from five operating variables:
- Boilup Ratio
- Column 2 Bottom Flow
- Column 2 Reflux Ratio
- Column 2 Pressure
- Column 1 Feed Temperature

Cross-validation was used to compare different regression models, after which the best-performing model was retrained using the complete prepared dataset.

The final optimization stage used an engineering-guided sampling strategy to generate 100,000 feasible operating conditions within the validated operating ranges. The trained ML model was used to screen these conditions and identify promising operating regions.

The top five AI-recommended operating conditions were then independently simulated in DWSIM. All five simulations converged, providing an independent process-simulation check of the ML recommendations.

The final outcome of the project is therefore not an AI-only optimum, but an ML-assisted process optimization workflow in which machine learning is used for rapid screening and DWSIM is used for final engineering validation.
